## 二、旗舰哲学（四条，缺一不可）

### ① 零重写
旗舰禁止从零造轮子。任何需求，先检索世界已有的最优解——顶级数学、顶级算法、顶级代码、顶级开源项目——直接复用、组合、超越。
> **反面教训**：早期用"学习型绝对位置嵌入"，后升级为业界标准的 **RoPE**（Su et al. 2021）；外推补洞直接用 **YaRN**（Peng et al. 2023）而非自造缩放。

### ② 集大成
旗舰每一行代码、每一个模块，都必须站在世界顶级成果之上；凡有更强的现成方案，立即替换自写。

### ③ 有尺子（最关键）
"最先进"如果由作者自己定义，就会退化成无人打分的美学竞赛。**每条自检都是可被独立实现交叉验证的数学不变量；每个基准都有真实对手（无注意力基线 / BM25 vs 随机）。**

尺子照出的不是胜利，是洞：
- KV-Cache 早期与全量重算偏差 **4.19** → 根因：`multiHeadAttention` 用 `seq=Q.shape[0]` 驱动 K/V 切片，KV-Cache 下只取了**第一个缓存 key** → 拆成 `qLen/kvLen` 后**逐位等价（0.00）**。
- 原生 RoPE **长度外推崩塌**（训练≤7、测 L=30：0.19 ≈ 基线 0.16）→ 用 **YaRN 推理期缩放**救回（L=30：0.19 → **0.52**）。
- 长归纳不是学不会，是**没训够**：4000 步只 0.47，10000 步才 0.90。

### ④ 闭环交付
成果必须完整开源至 GitHub，可运行、可复现、可验证，署名晨星。

## 五、已知短板（如实保留，不藏）

1. **长度外推仍被"缓解"而非"消灭"**：YaRN 把 L=30 外推从 0.19 拉到 0.52，但距同分布 L=20 的 0.89 仍有明显差距。
2. **YaRN 只在模型训够时生效**：欠训练（4000 步）时它仅小幅改善；需 ~6000 步才出现大幅外推增益。
3. **玩具规模**：三件实物验证的是"架构归纳偏置 / 引擎正确性 / 检索质量"，搭载的是玩具级小模型，**不宣称**在真实 LLM 规模达到 SOTA。

## 六、十层架构分解（详见 flagship-transformer）

1. 数学基础（线代 / 概率 / 数值稳定）
2. 自动微分引擎（反向模式）
3. 基础算子（matmul / 归一化 / 激活）
4. 注意力机制（因果多头 + RoPE）
5. 位置编码（RoPE → NTK/YaRN 外推）
6. 前馈与残差（RMSNorm / GELU / 残差流）
7. 层堆叠与预归一化
8. 训练闭环（AdamW + 梯度裁剪 + LR 衰减 + 可复现种子）
9. 推理引擎（KV-Cache 增量解码 + 采样）
10. 系统集成与评测（BM25 检索 + RAG 管线 + 基准打分）
